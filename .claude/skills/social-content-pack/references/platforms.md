# 各平台規格與寫法

字數上限依撰寫時各平台公開的規定；平台改規定時，以平台當下的限制為準並更新這份檔案。

| 平台           | 寫什麼     | 上限                                 | 寫法重點                                                            |
| -------------- | ---------- | ------------------------------------ | ------------------------------------------------------------------- |
| TikTok         | 影片說明   | 4,000 字元                           | 1～2 行就好：第一行重複開頭的衝突點；hashtag 3～5 個                |
| YouTube Shorts | 標題       | 100 字元                             | 關鍵字放前面，例如「ChatGPT 會議記錄：3 句話搞定」；20～40 字最好讀 |
| YouTube Shorts | 說明       | 5,000 字元                           | 前兩行會被看到：一句重點加行動呼籲；之後可放指令原文                |
| IG Reels       | 說明文字   | 2,200 字元                           | 第一行是鉤子（會被截斷，只顯示約 125 字元）；hashtag 3～5 個放最後  |
| IG 輪播        | 圖卡       | 最多 20 張，我們用 6～8 張           | 第 1 張只放鉤子標題（≤ 15 字）；中間一張一個重點；最後一張行動呼籲  |
| Threads        | 每則貼文   | 500 字元                             | 每則能獨立看懂；像聊天，不要條列太多；每則最多 1 個主題標籤         |
| FB             | Reels 說明 | 不限，建議 ≤ 300 字                  | 可以比 IG 多講一點背景，結尾問一個問題引導留言                      |
| X              | 每則貼文   | 280 字元（中文字算 2 個，約 140 字） | 只留一句重點加比喻；hashtag 最多 1～2 個                            |
| 小紅書         | 標題       | 20 字                                | 放觀眾會搜尋的關鍵字，例如「AI 寫會議記錄」「上班族效率」           |
| 小紅書         | 內文       | 1,000 字                             | 分段短句、適度 emoji；結尾放 5～8 個 `#標籤`                        |
| 小紅書         | 圖卡       | 3:4                                  | 封面大字標題；內頁一張一個步驟                                      |

## hashtag 選法

每次混搭三種，避免每篇都一樣被判定為重複內容：

- **大範圍**（流量大、競爭高）：`#AI` `#ChatGPT` `#人工智慧`
- **受眾**：`#上班族` `#職場` `#工作效率` `#職場技能`
- **主題**：依當天內容，例如 `#會議記錄` `#Email` `#Excel`

## 平台語氣差異

| 平台                  | 語氣                           |
| --------------------- | ------------------------------ |
| TikTok、Reels、Shorts | 快、直接，一句一個重點         |
| Threads、X            | 像在跟朋友聊天，可以有個人觀點 |
| FB                    | 較完整，可以多一點背景與故事   |
| 小紅書                | 筆記感、條列步驟、實用優先     |
