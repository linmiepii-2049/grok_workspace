# 需求問卷

一次問完，使用者已經回答的題目跳過。答案原樣寫進 `video/BRIEF.md`，後面每一步都讀這份檔案，不再回頭問。

## 問卷

```
1. 類型：解說型 B-roll／動效展示
2. 長度：大約幾秒或幾分鐘
3. 平台與比例（可複選）：9:16（Reels／Shorts／TikTok）、16:9（YouTube）、4:5（IG 貼文）、1:1
   主比例是哪一個？其他比例從主比例改版面，不重新設計
4. 主題或腳本：給主題我來寫口白；給腳本我只潤飾，不改內容
5. 參考圖：風格參考圖（可多張），以及每張要參考的地方（色彩／字體／構圖／動態感覺）
6. 聲音（可複選）：旁白／音樂／音效／都不要
   旁白：中文（MiniMax）或英文（ElevenLabs）；指定聲音就給 voice ID，沒指定就產生試聽讓使用者挑，同系列沿用上次的
   音樂：使用者提供檔案／我找免授權音樂
7. 字幕：要不要燒進畫面（解說型預設要）
8. 文字素材：logo、產品圖、數據、截圖
9. 期限與優先：先求快，還是先求精緻
```

## BRIEF.md 範本

```markdown
# <影片名稱>

- 類型：解說型 B-roll
- 長度：約 45 秒
- 比例：9:16（主）、16:9
- 平台：IG Reels、YouTube Shorts、YouTube
- 聲音：旁白（MiniMax，voice_id: <id>，model: speech-2.8-hd）、音樂（自找免授權）、音效
- 字幕：燒進畫面
- 參考圖：refs/a.jpg（色彩）、refs/b.jpg（字體與構圖）
- 素材：assets/logo.svg
- 優先：精緻
```

參考圖存到 `video/refs/`，方便之後追溯，但步驟 2 之後不再打開。
