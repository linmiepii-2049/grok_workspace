# 多比例輸出

每個比例是 `video/` 底下一個獨立的 HyperFrames 專案（`9x16/`、`16x9/`、`4x5/`、`1x1/`）。先把主比例完整做完、自檢通過，再複製成其他比例，只改版面，不改時間軸和文案。這樣其他比例的成本主要在調版面，不用重新設計。

## 尺寸

| 資料夾  | 尺寸      | 用途                  |
| ------- | --------- | --------------------- |
| `9x16/` | 1080×1920 | Reels、Shorts、TikTok |
| `16x9/` | 1920×1080 | YouTube               |
| `4x5/`  | 1080×1350 | IG 貼文               |
| `1x1/`  | 1080×1080 | 通用貼文              |

## 平台安全區

平台介面會蓋住畫面邊緣，重要文字和字幕不能放在那裡。`scripts/qa.sh` 會依資料夾名稱自動用 `--caption-zone` 檢查下方區域，所以要用上面的資料夾名稱；右側和上方在 L2 看總表時檢查。

| 比例     | 避開的區域（比例為畫面的幾分之幾） | 原因                           |
| -------- | ---------------------------------- | ------------------------------ |
| 9:16     | 下方 20%、右側 12%、上方 10%       | 說明文字、按讚留言按鈕、帳號列 |
| 16:9     | 下方 10%                           | 播放器進度列                   |
| 4:5、1:1 | 下方 8%                            | 貼文介面                       |

數字來自 IG、TikTok、Shorts 介面的常見重疊範圍，取三者中最保守的值。

## 改版面的順序

1. 複製主比例資料夾（排除 `.hyperframes/`、`.qa/`），改 `index.html` 的 `data-resolution`、viewport meta、`html, body` 的寬高、根元素的 `data-width`、`data-height`，以及 canvas 的尺寸（p5 的 `createCanvas`、three.js 的 `setSize`）
2. 文字大小用畫面短邊的比例（例如 `font-size: 6vmin`），換比例時大多會自動適應
3. 橫式改直式：左右並排的元素改成上下堆疊；直式改橫式：反過來
4. 版面差異寫成另一個 `<style>` 區塊放在原本樣式後面，覆蓋位置和大小就好，主比例改了樣式也容易同步
5. 跑 `scripts/qa.sh`，只修出界和重疊，不重新做動畫。注意字幕的進場位移：字幕從下方 16px 滑入時，進場那一瞬間可能壓到安全區，`check` 會抓到
6. 旁白音檔由 `retime.mjs` 複製到每個比例；HyperFrames 的素材路徑不能用 `../` 跨出專案資料夾
