# 參考圖 → FRAME.md

參考圖是最貴的輸入：每次打開都要花看圖 token。所以只在這一步看一次，把看到的東西全部轉成文字和數字，寫進 `video/FRAME.md`，之後只讀這份檔案。

## 怎麼看

每張圖只抓使用者在 BRIEF 指定要參考的面向。沒指定就全部抓。

| 面向 | 要寫下的東西 | 例子 |
|---|---|---|
| 色彩 | 背景、主色、強調色、文字色的 hex，以及比例 | 背景 `#0B0D12` 70%、主色 `#4F7CFF` 20%、強調 `#FFB547` 10% |
| 字體 | 襯線或無襯線、字重、大小對比、字距 | 無襯線粗體標題，標題和內文大小約 4:1，字距略緊 |
| 構圖 | 留白、對齊、網格、主體位置 | 大量留白、左對齊、主體偏左三分之一 |
| 質感 | 平面、漸層、顆粒、光暈、玻璃、陰影 | 細顆粒加柔光暈，沒有硬陰影 |
| 動態個性 | 從靜態圖推測的節奏 | 俐落、少量彈性，進場以位移加淡入為主 |

色彩用 hex 寫下，不要寫「深藍色」，因為文字描述在後續步驟沒辦法直接用。

## FRAME.md 格式

以 HyperFrames 的 `FRAME.md` 格式為準（`/hyperframes` 的 frame preset 可以當範本），最上面加一段來源：

```markdown
<!-- 來源：refs/a.jpg（色彩）、refs/b.jpg（字體與構圖），擷取日期 2026-10-29 -->
```

中文字型寫在 FRAME.md 的字體段，實際檔案的處理方式見 `zh-typography.md`。

## 沒有參考圖時

從 HyperFrames 的 frame preset 挑一個最接近 BRIEF 的，複製過來後只改需要改的地方，並在來源寫明 preset 名稱。
