# 風格：beige-teal（文青米白）動態版

來源：輪播版型 `carousel/themes/beige-teal/`（使用者的 Canva 參考，見 memory `tristan-carousel-style`）。沒有另外的參考圖。

- 底色 `#F5EFE7` 米白，平塗，不加紙紋
- 墨色 `#3A3836`：所有要讀的字
- 灰綠 `#6E9E9B`：結構（標籤、底線、框線、品牌色塊）
- 磚紅 `#D2483A`：唯一強調色，每個畫面只有一處（關鍵詞、紅筆劃掉、數字）
- 杏橘 `#EDB27A`：裝飾（斜紋、圓點），不承載文字
- 卡片 `#FBF8F3`：輸入框、回覆卡，1.5px `#3A3836` 14% 邊框，陰影 0 12px 32px rgba(58,56,54,.10)
- 標題：思源黑體 Thin（200）縱向拉長 1.18 倍，強調字加粗一級（300）並用磚紅
- 內文：思源黑體 Light／Regular；拉丁字與數字：Montserrat 700～800
- 不用：襯線體、等寬字小標、膠囊形按鈕、光暈、深色底
