## 怎麼用

1. 每一招都能直接複製，貼到 ChatGPT、Claude、Gemini 都可以
2. 把【】裡的字換成你自己的狀況，寫得越具體，結果越好
3. 每一招都照「角色、背景、任務、格式」四段來寫，就像交代新人做事
4. AI 給的是初稿，不是定稿。每招下面的「品味提醒」告訴你：最後該挑什麼、改什麼
5. 公司機密、客戶個資不要貼進去，先把名字和數字換掉

## 一、寫信與訊息

### 01 請假信｜客氣，但不卑微

情境：要請假，又不想寫成罐頭信。

```
你是我的秘書。
背景：我【週五】因為【家裡有事】要請假【一天】，手上的【專案報告】會在【週四】前交接給【同事小王】。
任務：寫一封請假信給我的主管。
格式：語氣客氣、不要過度道歉，100 字以內。
```

品味提醒：把「造成不便，敬請見諒」這類套話刪掉，留下「工作怎麼安排」，主管最在意的是這句。

### 02 催進度｜催到人，不得罪人

情境：對方拖了好幾天，你需要他動起來。

```
你是很會做人的資深同事。
背景：我在等【其他部門的同事】給【報價資料】，原本約【上週三】，已經晚了【5 天】，我【下週一】要交給客戶。
任務：幫我寫一則催進度的訊息。
格式：先給對方台階下，再講清楚我最晚什麼時候需要，最後問他需不需要幫忙。3 句以內，適合用 Teams 或 LINE 傳。
```

品味提醒：AI 常寫得太客氣，對方會以為不急。截止日一定要留著，而且要寫明確的日期。

### 03 婉拒｜拒絕額外工作，不傷關係

情境：主管或同事又丟事情過來，你真的接不下。

```
你是懂職場溝通的顧問。
背景：【主管】請我接【新的活動企劃】，但我手上已經有【兩個專案】，【月底】都要交。
任務：幫我寫一段回覆，婉拒或延後這件事。
格式：先表示理解這件事很重要，再說明我目前的工作量，最後提出一個替代方案（例如延後、只做一部分、推薦其他人）。150 字以內。
```

品味提醒：替代方案要選你真的做得到的那個，AI 列的選項不一定都適合你的處境。

### 04 道歉信｜出錯了，誠懇又有解法

情境：寄錯檔、算錯數字、延誤交期。

```
你是處理過很多危機的客服主管。
背景：我把【錯誤版本的報價單】寄給了【客戶 A】，【今天早上】才發現。
任務：寫一封道歉信給客戶。
格式：第一句就承認錯誤，接著說明影響範圍、已經做的補救，最後附上正確版本。不要推卸責任，200 字以內。
```

品味提醒：檢查 AI 有沒有替你承諾做不到的事（例如「保證不再發生」），寫進信裡就要做到。

### 05 長信改短｜讓主管秒懂

情境：你寫了一大段，主管已讀不回。

```
你是我主管的特助，很了解他沒時間看長信。
背景：下面是我寫好的信。
【貼上你的信】
任務：幫我改寫，讓主管 10 秒內看懂。
格式：第一行寫結論或我需要他做的決定，接著最多 3 個重點，每點一行。原本的細節放在最後的「補充」。
```

品味提醒：結論那一行要你自己判斷。AI 抓的重點不一定是主管最在意的。

## 二、會議

### 06 會前議程｜開會不再離題

情境：你要主持一場會議。

```
你是很會主持會議的專案經理。
背景：我要開一場【30 分鐘】的會，參加的人有【業務、設計、工程各一位】，目的是【決定新產品的上市日期】。
任務：幫我排會議議程。
格式：每個議題寫上負責人和分配時間，最後留 5 分鐘確認待辦。用表格呈現。
```

品味提醒：議題太多時，刪掉「這次不需要決定」的事，一場會只做一個決定。

### 07 會議記錄｜錄音丟進去，記錄就出來

情境：開完會還要花 1 小時寫記錄。

```
你是專業的會議記錄員。
背景：下面是【產品週會】的逐字稿，參加的人有【小林（PM）、阿美（設計）、大衛（工程）】。
【貼上逐字稿】
任務：整理成會議記錄。
格式：分成「決議」「待辦（誰、做什麼、哪天前）」「還沒結論的問題」三段。閒聊和重複的內容不要寫。
```

品味提醒：逐字稿常把人名、專有名詞聽錯，交出去前對一次名字和數字。

### 08 抓待辦｜誰要做什麼，一次列清楚

情境：會議記錄寫了，但沒人知道自己要做什麼。

```
你是幫團隊追進度的助理。
背景：下面是會議記錄。
【貼上會議記錄】
任務：把裡面所有要做的事找出來。
格式：表格，欄位是「待辦事項、負責人、期限、狀態」。沒寫負責人或期限的，標成「待確認」。
```

品味提醒：「待確認」的那幾項，就是你會後要追的事。不要讓 AI 自己幫你猜負責人。

### 09 會後追蹤信｜讓大家記得答應過什麼

情境：會議結束，要寄信給大家確認。

```
你是做事很有條理的專案經理。
背景：今天【和客戶開了需求會議】，結論是【下面這幾點】。
【貼上結論或待辦】
任務：寫一封會後追蹤信給所有參加的人。
格式：先謝謝大家，再列出決議和待辦（負責人、期限），最後請大家在【週三】前回覆有沒有遺漏。200 字以內。
```

品味提醒：寄給客戶時，把內部才講的話刪掉，例如「這部分我們其實還沒把握」。

### 10 準備發言｜開會時不再腦袋空白

情境：會議上要報告，或想提出意見。

```
你是我的簡報教練。
背景：明天的會要討論【是否導入新的請款系統】，我的立場是【贊成，但希望分階段導入】。
任務：幫我準備發言內容。
格式：一句話講立場，3 個理由，最後預想 2 個別人可能的反對意見和我的回應。整段 1 分鐘內講得完。
```

品味提醒：3 個理由裡，留下你自己真的相信的。講你不相信的理由，會被問倒。

## 三、報告與簡報

### 11 週報｜5 分鐘寫完，主管愛看

情境：每週五都要寫週報。

```
你是我的工作助理。
背景：這週我做了這些事：
【用條列隨手寫下，不用整理】
任務：整理成給主管的週報。
格式：分成「本週完成」「進行中（進度 %）」「需要協助」三段，每點一行。先寫成果，再寫做了什麼。
```

品味提醒：「需要協助」寫得具體，主管才幫得上忙。這一段比「本週完成」更重要。

### 12 數據變重點｜一張表，看出 3 件事

情境：手上有一張數字表，不知道該講什麼。

```
你是資深的數據分析師。
背景：下面是【第三季各區的業績】。
【貼上表格】
任務：找出最值得跟主管報告的 3 個重點。
格式：每個重點一句話加一個數字佐證，最後加一句「建議下一步」。
```

品味提醒：AI 會找出「數字上最明顯」的事，但「主管最在意」的事你更清楚，兩者不同時，選後者。

### 13 簡報大綱｜不再對著空白投影片發呆

情境：要做一份簡報，不知道從哪開始。

```
你是很會說故事的簡報顧問。
背景：我要對【部門主管們】報告【導入 AI 客服的提案】，時間【10 分鐘】。
任務：幫我排簡報大綱。
格式：8 頁以內，每頁寫標題和一句重點。第一頁就講結論，最後一頁寫需要大家決定的事。
```

品味提醒：每頁只留一個重點。AI 塞得進去的，觀眾不一定吸收得了。

### 14 一頁摘要｜長報告濃縮給忙碌的人

情境：一份 30 頁的報告，主管只想看一頁。

```
你是高階主管的幕僚。
背景：下面是【市場調查報告】的內容。
【貼上報告內容】
任務：寫成一頁摘要。
格式：背景（2 句）、主要發現（3 點）、建議（2 點）、風險（1 點）。整份 300 字以內。
```

品味提醒：摘要裡的每個數字都回原文對一次。AI 濃縮時最容易把數字張冠李戴。

### 15 講給外行人聽｜專業內容，誰都聽得懂

情境：要跟其他部門或客戶解釋你的專業。

```
你是很會用比喻的老師。
背景：我是【半導體製程工程師】，要跟【業務同事】解釋【為什麼良率會影響交期】。
任務：幫我用白話解釋。
格式：先用一個生活比喻，再用 3 句話講清楚原理，不要用專業術語。
```

品味提醒：AI 會給好幾個比喻，挑對方生活中最熟悉的那個。比喻要對方一聽就懂，不是越巧妙越好。

## 四、Excel 與資料

### 16 寫公式｜用講的，AI 寫給你

情境：知道要算什麼，但不會寫公式。

```
你是 Excel 專家。
背景：我的表格 A 欄是【日期】、B 欄是【業務姓名】、C 欄是【金額】。
任務：寫一個公式，算出【每位業務在 10 月的總金額】。
格式：給我公式，告訴我貼在哪一格，再用一句話解釋公式在做什麼。
```

品味提醒：先在幾筆資料上手算一次，對得起來再整欄套用。

### 17 整理亂表｜格式不一致，一次統一

情境：別人給的表格，日期、電話、名字格式全都不一樣。

```
你是資料整理專家。
背景：下面是一份客戶名單，格式很亂。
【貼上前 20 筆資料】
任務：告訴我怎麼統一格式。
格式：日期改成 YYYY/MM/DD、電話改成 09XX-XXX-XXX、公司名稱去掉多餘空白。給我 Excel 的作法（公式或步驟），不要只給整理好的結果。
```

品味提醒：要 AI 教你「方法」，不要只給「結果」。資料有幾千筆時，方法才帶得走。

### 18 找異常｜一眼看出哪裡怪怪的

情境：報表數字很多，擔心有算錯或輸入錯。

```
你是嚴謹的稽核人員。
背景：下面是【這個月的費用報銷明細】。
【貼上表格】
任務：找出看起來不合理的資料。
格式：列出可疑的那幾筆，說明為什麼可疑（例如金額特別大、日期在假日、重複報銷），依可疑程度排序。
```

品味提醒：AI 標出來的是「可疑」，不是「有錯」。每一筆都要你去確認，不要直接拿去質問同事。

### 19 樞紐分析｜一步一步教你做

情境：聽說樞紐分析很好用，但從來沒做過。

```
你是很有耐心的 Excel 老師。
背景：我有一張【銷售明細】，欄位是【日期、地區、產品、數量、金額】。我想看【每個地區、每個月的銷售金額】。
任務：教我用樞紐分析表做出來。
格式：一步一步寫，每一步只做一個動作，告訴我要點哪裡、拖哪個欄位到哪個區域。
```

品味提醒：做出來之後，自己決定要看「哪個角度」。同一張表，按地區看和按產品看，會得到完全不同的結論。

### 20 看懂別人的公式｜接手不再一頭霧水

情境：接手前同事的檔案，看不懂裡面的公式。

```
你是 Excel 專家，很會解釋。
背景：我接手了一份報表，裡面有這個公式：
【貼上公式】
A 欄是【…】、B 欄是【…】。
任務：解釋這個公式在算什麼。
格式：先一句話講它的用途，再拆開說明每一段，最後告訴我有沒有更簡單的寫法。
```

品味提醒：AI 提出「更簡單的寫法」時，先確認其他工作表沒有引用這格，再決定要不要改。

## 五、溝通與決策

### 21 回客訴｜安撫情緒，也解決問題

情境：收到一封很生氣的客訴。

```
你是有 10 年經驗的客服主管。
背景：客戶寫了下面這封信。我們的狀況是【出貨延遲 3 天，原因是物流塞車，最快明天到貨】。
【貼上客訴信】
任務：寫一封回覆。
格式：先回應對方的感受，再說明原因（不要找藉口），接著講具體的解決方式和補償【例如運費退還】。200 字以內。
```

品味提醒：刪掉 AI 寫的「非常非常抱歉」這類重複道歉。一次誠懇的道歉，加上具體的解法，比道歉三次有用。

### 22 比較方案｜選擇困難時，幫你理清楚

情境：兩三個選項各有好壞，決定不了。

```
你是理性的決策顧問。
背景：我們要選【專案管理工具】，候選是【Notion、Trello、Asana】，團隊【8 個人】，預算【每月 3,000 元】，最在意【好上手】。
任務：幫我比較這幾個方案。
格式：表格比較（價格、優點、缺點、適合誰），最後依我在意的條件給一個建議，並說明理由。
```

品味提醒：最後的決定要你來做。AI 不知道你們團隊的習慣，也不知道誰會抱怨。

### 23 寫提案｜讓主管願意說好

情境：你有一個想法，想說服主管支持。

```
你是很會寫提案的企劃。
背景：我想提議【每週五下午空出 2 小時，讓大家學 AI 工具】，部門有【12 個人】，主管最在意【產出不能變少】。
任務：幫我寫一份提案。
格式：問題（現在的痛點）、提案（要做什麼）、效益（盡量量化）、成本與風險、試行計畫（先試 1 個月）。500 字以內。
```

品味提醒：「效益」裡的數字要有根據。AI 估的數字看起來很漂亮，但被問「怎麼算的」答不出來就破功了。

### 24 模擬主管提問｜報告前先被問一輪

情境：明天要報告，怕被問倒。

```
你是一位很嚴格、很重視數字的主管。
背景：我明天要報告下面這份內容。
【貼上報告或簡報大綱】
任務：用主管的角度，問我 5 個最尖銳的問題。
格式：一次只問一題，等我回答後，告訴我回答哪裡不夠好，再問下一題。
```

品味提醒：AI 問的問題不一定是你主管會問的。把你過去真的被問過的問題補進去，練習會更準。

### 25 難開口的對話｜談加薪、反映問題、說不

情境：有些話很重要，但很難開口。

```
你是職涯教練。
背景：我想跟主管談【加薪】，我的理由是【過去一年接了 2 個新專案、業績成長 20%】，主管的個性是【重視數據、不喜歡繞圈子】。
任務：幫我準備這場對話。
格式：開場第一句怎麼說、要講的 3 個重點、主管可能的 3 種反應和我的回應。
```

品味提醒：AI 寫的台詞照念會很生硬，把它換成你平常講話的語氣，再練習說出口。

## 六、學習與整理

### 26 讀長文件｜30 頁，3 分鐘抓到重點

情境：合約、規範、研究報告太長，沒時間細看。

```
你是幫忙讀文件的助理。
背景：下面是【新的公司差旅規定】。我是【常出差的業務】。
【貼上文件內容】
任務：告訴我跟我有關的重點。
格式：先列 5 個跟我有關的重點，再列出「跟舊規定不一樣的地方」，最後列出「我需要特別注意、不然會出事的條款」。
```

品味提醒：合約和規定裡「會出事」的條款，一定要回原文看一次，不要只看 AI 的摘要。

### 27 學新工具｜7 天上手計畫

情境：工作需要學一個新工具或新技能。

```
你是很會教新手的老師。
背景：我要學【Power BI】，目的是【做部門的業績儀表板】，我【完全沒基礎】，每天能花【30 分鐘】。
任務：幫我排一個 7 天的學習計畫。
格式：每天寫學習目標、要做的練習、做完的成果。第 7 天要能做出一個簡單的成品。
```

品味提醒：計畫跟不上就調整，不要硬撐。學東西重點是「做出成品」，不是把課程看完。

### 28 整理筆記｜亂七八糟的筆記，變成好找的資料

情境：筆記東寫一句、西寫一句，要用時找不到。

```
你是很會整理資訊的圖書館員。
背景：下面是我這個月記下來的筆記，很零散。
【貼上筆記】
任務：幫我分類整理。
格式：依主題分類，每類下面條列重點，重複的內容合併，最後列出「還沒處理的事」。
```

品味提醒：分類方式要照你「之後怎麼找」來決定，不是照 AI 覺得合理的方式。

### 29 模擬面試｜面試前先練 3 輪

情境：要面試新工作，或是內部轉調。

```
你是【科技業】的資深面試官。
背景：我要面試【產品經理】，下面是職缺說明和我的履歷重點。
【貼上職缺說明】
【貼上履歷重點】
任務：模擬面試。
格式：一次問一題，總共 5 題，混合經歷題和情境題。我回答後，先給我評分（1–5 分），再告訴我怎麼回答更好。
```

品味提醒：AI 修改後的回答通常太完美、像背稿。保留你自己真實的例子，面試官要聽的是你的故事。

### 30 萬用起手式｜不知道怎麼問，就讓 AI 先問你

情境：前面 29 招都不適用，或是你連要怎麼問都不知道。

```
我想請你幫我【做一件事，例如規劃部門尾牙】。
在開始之前，先問我 3 個你最需要知道的問題。
等我回答後，再開始做。
```

品味提醒：這招能用在任何事情上。AI 問的問題，常常就是你自己沒想清楚的地方。
