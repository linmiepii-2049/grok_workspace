JT-PROJECTS

雲端工作室

一個放在雲端的 monorepo 工作區。無論拿起手機、平板還是 Mac，打開 Claude Code 就能接著做；產出的成品會自動歸檔到 Cloudflare R2 / D1，換裝置也不會遺失。

為什麼好用

📱 任何裝置都能開工

工作環境在雲端容器裡，裝置只是入口。通勤用手機下指令，回家用 Mac 接手。

🗂️ 成品自動歸檔

放進 outputs/ 的檔案推上 GitHub 後，由 Actions 自動歸檔到 R2，版本全保留。

🧠 記憶跟著 repo 走

偏好與規則寫在 memory/，進版控，每個 session 開工前先讀。

🧩 共用 Skills

.claude/skills/ 從 JT-Skills repo 自動同步，所有裝置用同一套技能。

一個專案的流程

  1. 建立專案：npm run jt -- new <slug> "名稱"，產生 projects/<yyyy-mm>-<slug>/
  2. 在專案資料夾裡寫草稿、原始碼
  3. 把成品放進 outputs/（圖片、影片、HTML、文案、簡報）
  4. commit 並推到 main，小檔自動歸檔；影片用 npm run jt -- archive 直傳 R2
